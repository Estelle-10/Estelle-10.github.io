题目1：math_rsa

需要对等式左边进行化简,有：

(x2+1)(y2+1)=(x−y)2+(xy+1)2(x^2 + 1)(y^2 + 1) = (x - y)^2 + (xy + 1)^2 (x2+1)(y2+1)=(x−y)2+(xy+1)2

接着，将 (xy+1)2(xy + 1)^2(xy+1)2 展开并改写为含有 (xy−1)2(xy - 1)^2(xy−1)2 的形式：

(xy+1)2=(xy−1)2+4xy(xy + 1)^2 = (xy - 1)^2 + 4xy (xy+1)2=(xy−1)2+4xy

将上述两个结论代入原等式的左边，替换掉 (x2+1)(y2+1)(x^2 + 1)(y^2 + 1)(x2+1)(y2+1)：

(x−y)2+(xy−1)2+4xy−2(x−y)(xy−1)=4k+4xy(x - y)^2 + (xy - 1)^2 + 4xy - 2(x - y)(xy - 1) = 4k + 4xy (x−y)2+(xy−1)2+4xy−2(x−y)(xy−1)=4k+4xy

等式两边同时消去 4xy4xy4xy：

(x−y)2−2(x−y)(xy−1)+(xy−1)2=4k(x - y)^2 - 2(x - y)(xy - 1) + (xy - 1)^2 = 4k (x−y)2−2(x−y)(xy−1)+(xy−1)2=4k

观察等式左边，这正好是一个完美的完全平方式 a2−2ab+b2=(a−b)2a^2 - 2ab + b^2 = (a - b)^2a2−2ab+b2=(a−b)2：

((x−y)−(xy−1))2=4k((x - y) - (xy - 1))^2 = 4k ((x−y)−(xy−1))2=4k

展开括号内部进行因式分解：

(x−y−xy+1)2=4k(x - y - xy + 1)^2 = 4k (x−y−xy+1)2=4k

((1−y)(x+1))2=4k((1 - y)(x + 1))^2 = 4k ((1−y)(x+1))2=4k

(1−y)2(x+1)2=4k(1 - y)^2(x + 1)^2 = 4k (1−y)2(x+1)2=4k

现在将题目中 xxx 和 yyy 的定义代入化简后的等式中。
已知 x=ϕ−1x = \phi - 1x=ϕ−1，所以：

x+1=ϕx + 1 = \phi x+1=ϕ

已知 y=2u+1y = 2u + 1y=2u+1，所以：

1−y=−2u1 - y = -2u 1−y=−2u

将这两个结果代入化简后的等式：

(−2u)2(ϕ)2=4k(-2u)^2(\phi)^2 = 4k (−2u)2(ϕ)2=4k

4u2ϕ2=4k4u^2\phi^2 = 4k 4u2ϕ2=4k

u2ϕ2=ku^2\phi^2 = k u2ϕ2=k

两边同时开平方，得到了核心结论：

uϕ=ku\phi = \sqrt{k} uϕ=k​

根据ϕ=(p−1)(q−1)=n−p−q+1\phi = (p - 1)(q - 1) = n - p - q + 1ϕ=(p−1)(q−1)=n−p−q+1，因为 ppp 和 qqq 相比 nnn 来说非常小（大约是 n\sqrt{n}n​ 量级），所以 ϕ\phiϕ 的值非常接近 nnn，且略小于 nnn。
利用这一特性，我们可以得出：

u≈knu \approx \frac{\sqrt{k}}{n} u≈nk​​

由于 ϕ<n\phi < nϕ<n，所以实际的 uuu 一定略大于 kn\frac{\sqrt{k}}{n}nk​​。
因此，我们可以先计算出估算值 u_estimate = isqrt(k) // n，然后从该估算值开始向上进行小范围的穷举爆破。一旦找到一个 uuu 能够整除 k\sqrt{k}k​，我们就可以计算出 ϕ=ku\phi = \frac{\sqrt{k}}{u}ϕ=uk​​，进而算出私钥 ddd 并解密拿到 Flag。

题目3：NumberGuesser

先生成624个32bits的hint，然后用同一个PRNGtwist得到新的一轮，生成128bits的key，并用iv=seed*2AES_CBC加密flag
目的是通过624个hint恢复key，然后利用flag头已知的VNCTF{局部爆破出seed，但是只有10次查询机会
在CPython实现MT19937的“twist”更新中，状态长度n=624，参数M=397，每一轮的新状态new_mt[kk]只由旧状态的mt[kk]，mt[kk+1]和mt[kk+M]决定
因此想要恢复新一轮的前4个32bit，只需要查询旧一轮的0,1,2,3,4，397,398,399，400即可，这样可以得到完整的key
然后利用key解密第一块密文，明文开头前6字节固定是VNCTF{，可以和密文做XOR恢复6字节的IV，剩下两个字节爆破然后验证即可
