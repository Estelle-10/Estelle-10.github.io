渐进超负荷（双进阶法）

每个动作都有次数区间（如 8–12 次）。当你所有组都能标准完成区间上限，下次训练加 2.5kg（哑铃加 1.25kg/只），次数会回落，再继续堆次数。如此循环。

⏱️

组间休息

复合动作（卧推、划船、推举）休息 90–120 秒；孤立动作（飞鸟、弯举、侧平举）休息 60–90 秒。每组结束保留 1–2 次余力（RIR 1–2）。右下角有休息计时器。

🔥

热身流程

体重追踪

每周晨起空腹称重并记录，看周平均值趋势（目标：每月 +1~2kg）

    参考一日餐单（约 2500 kcal / 130g 蛋白）

    餐次内容
    早餐燕麦 60g + 全蛋 3 个 + 牛奶 300ml
    加餐香蕉 1 根 + 坚果 30g / 蛋白粉半勺
    午餐米饭 250g + 鸡胸肉/牛肉 150g + 蔬菜
    练前香蕉/面包（训练前 1 小时）
    练后蛋白粉 1 勺（约 25g 蛋白）+ 快碳
    晚餐米饭/红薯 + 鱼虾/瘦肉 150g + 蔬菜

    恢复与睡眠

    • 睡眠 7–9 小时，肌肉在睡眠中生长，22:00–02:00 是修复黄金期
    • 同一肌群两次训练间隔 48–72 小时
    • 休息日也按增肌热量吃，身体在休息日长肌肉
    • 每 2–4 周同角度拍对比照（前/侧/后），比镜子更诚实
    可选补剂（非必需）：乳清蛋白粉（凑不够蛋白时）、肌酸 3–5g/天。

    阶段目标（新手福利期 0–6 个月）

    • 体重：65kg → 70–73kg
    • 平板卧推：32.5kg → 50kg 做组
    • 哑铃推肩：12.5kg → 17.5–20kg/只
    • 标准俯卧撑：连续 25 个；引体向上：从 0 到 5 个
    前 3 个月别换计划、别上花哨技巧，把基础复合动作的重量稳步推上去就是最好的计划。
